# Engineering Principles

1. **Truth First** — only verified, sourced data enters the Knowledge Graph. Never fabricate.
2. **Explainable AI** — every recommendation must have a traceable reason. No black boxes.
3. **Human Approval** — Atlas proposes, humans decide, system executes. Always.
4. **Closed Loop** — every action is measured. Learning is not optional.
5. **Documentation Driven** — architecture is decided in writing before code is written.
